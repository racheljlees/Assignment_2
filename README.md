# Lab Assignment No 2 Networks, Geodemographics and Spatial Microsimulation

This is a Repository that includes the material and labs required for Assignment No. 2 of the module GG4257 - Urban Analytics: A Toolkit for Sustainable Urban Development at the University of St Andrews.

## Consider

* The /data folder contains most of the datasets required for the analysis. Some large geographical datasets may not be included in the repository due to GitHub file-size limitations. Follow the instructions below to obtain any missing datasets.
* You must install the `ua.yml` environmental file to get all the required libraries.

## Data and Reproducibility

Most datasets used in this assignment are included in the repository. However, some large geographical datasets cannot be stored directly on GitHub because of file-size limitations. These datasets must be downloaded separately from Google Drive.

Download the large datasets: [https://drive.google.com/drive/folders/1AInSLh0dV97H6HrHc_KxAov-nCza7492?usp=drive_link]

To reproduce the analysis:

1. Download the "SIMD_2020" and "boundaries" folder using the link above.

2. Ensure the folders are both saved in the "data" folder

3. Keep the notebook and data folders in their original  locations.

4. Open Assignment_2.ipynb in JupyterLab and run the notebook cells in order.
